### projects

#### `SNIPE`

Robinhood Chain CLI sniper for new launches.

Tracks fresh tokens, early wallet bursts and strong-wallet convergence using launch + provider + onchain context.

```text
new token
   ↓
wallet activity
   ↓
GMGN / Pons / fomo / RH chain
   ↓
LOCK / TRACK / DROP
```

> currently building

<br>

#### `crowd`

CLI for checking who's actually behind token activity.

```bash
npx crowd read <token>
```

wallet count · repeat wallets · holder activity · sells · concentration
